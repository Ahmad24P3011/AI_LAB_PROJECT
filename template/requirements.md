# Course Requirements: AI Lab Final Project

These are the official requirements from the course. The project must satisfy
all of them. Do not change this file.

## 1) Problem Statement
- Clearly define the problem.

## 2) Dataset
- Describe the dataset and its source.
- Explain input features and target/output.

## 3) Data Preprocessing
- Handle missing values.
- Remove duplicates.
- Encode categorical data.
- Perform feature scaling if required.
- Split the dataset into training and testing data.

## 4) Exploratory Data Analysis
- Analyze the dataset.
- Use appropriate visualizations and graphs.
- Identify important patterns and relationships.

## 5) Train 2 (min) to 4 (max) Machine Learning / Deep Learning / NLP Models
- Select appropriate models according to the problem.
- Train and test each model.
- Use proper evaluation metrics.

## 6) Comparison of Above Models (suggest best model)
- Compare models using appropriate evaluation metrics.
- Explain why the selected model is the best (understanding of the selected
  model is a must).

## 7) Integrate Your Model with a Web App / Mobile App
- Deploy the selected model in a simple web app or mobile app.
- Demonstrate how users can provide input and receive predictions/results.

## 8) Submission
- Source code: GitHub link is required
- Project report
- Dataset/source link
- Demo of the web/mobile application
